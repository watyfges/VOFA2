# VOFA2 移动端（远程调参客户端）

PC 端 VOFA2 打开「远程调参」后就是局域网服务端。手机连上去只能操作右侧调参栏里**已有**的
滑块、数值框、开关、命令按钮和一键发送；不能新增或修改命令、命令组、协议和串口参数。

## 端口

| 用途 | 协议 | 端口 |
| --- | --- | --- |
| 控制通道 | WebSocket over TCP | 47900（PC 端可改，发现报文里带实际端口） |
| 服务发现 | UDP | 47901（固定） |

## 联调前先在 PC 上确认

1. 工具栏「远程调参」→ 勾选「启用远程调参服务」。
2. 对话框显示「运行中 · 端口 47900」并列出 `ws://<IP>:47900`。首次启用时 Windows 防火墙会询问，
   选择允许「专用网络」，否则手机连不上。
3. 手机与 PC 在同一局域网。
